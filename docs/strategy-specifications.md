# Executable baseline mapping

Source PDFs are read-only references under `../oanda-local/references/` (relative to project root); hashes are recorded in `source-manifest.json`. The files aggregate variants and visual/ASR descriptions. The decisions below are explicit engineering interpretations, not claims that every video uses these exact rules. Thresholds omitted by a PDF are assumptions. All decisions happen after candle close; fixed minute expiries in the PDFs are generalized to configured integer candle horizons.

All crossovers use previous <= and current > for UP, previous >= and current < for DOWN. SMA requires its full window; EMA is seeded with an SMA; RSI and ATR use Wilder smoothing. Stochastic is rolling %K followed by SMA K and D smoothing. Bollinger uses population standard deviation. Undefined/warming indicators abstain. No centered averages or backward filling are used.

## Causal swing confirmation

`ZigZag` maintains a provisional close extreme and trend direction privately. An initial ATR-sized move establishes direction without emitting a signal. A later extreme is confirmed only when (a) close has reversed at least `zigzag_atr * current ATR8` (default 1.0 ATR) and (b) at least `zigzag_depth` bars (default 6) have closed since that candidate extreme. A newer equal/more extreme close moves the provisional candidate and resets its age. Emitted events contain the original `pivot_index` plus the current `confirmed_index`. Only the latter can trigger a prediction. Previously emitted events are never rewritten.

Using close extremes and an ATR threshold is a documented non-repainting substitute for the underspecified platform ZigZag. Confirmation can occur much later than the charted swing and will omit setups from a repainting retrospective chart. Strategy 05 checks the historical candidate's already-known channel contact but enters only at confirmation. It requires a fresh oscillator cross near confirmation rather than pretending the original swing was known in real time.

Fractals use strict high/low comparisons across the full five-candle window. A pivot at index 10 becomes known at index 12; strategy 07 can first act on candle 13. This intentionally shifts entry timing from any visual interpretation that uses a retrospectively plotted mark at index 10.

## Horizons and evidence

The same votes are evaluated at every configured horizon; this first version does not claim a learned horizon-specific forecast. Thresholds can vary by horizon and reports measure each separately. Fixed regime weights are assumptions, not fitted win probabilities. Synthetic sample results must not be used to select supposedly profitable parameters. Optional PDF variants require separately named specifications and tests before being added.
